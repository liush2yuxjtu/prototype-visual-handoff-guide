Prototype Delivery · Visual-first

不要解释给我听。
先让我看见，再让我上手。

把 Matt Pocock 的保真度梯子，改造成一套适合 ChatGPT → Human → Coding Agent 的可视化交付路由。

唯一原则：不用固定走完整流程。选择“足以回答当前问题的最低复杂度可视化”。所有“改动”默认用 Before → Now Progressive SVG Diff：两个 artifact 同时存在，左边 BEFORE 保持可见，右边 NOW 用 progressive line-draw 逐线生成。
01 · Fidelity ladder

从“理解”到“真实运行”

这是一把梯子，不是一条必须逐级执行的流水线。答案在哪一层已经足够清楚，就停在哪里。

02 · ChatGPT-native router

但我们的交付方式不必照着梯子走

点左边一种改动，右边直接播放对应的 Before → Now Progressive SVG Diff。每个 SVG 都是两个 artifact：BEFORE [左] → NOW [右]；NOW 逐线生成。
推荐 · BEFORE → NOW PROGRESSIVE SVG DIFF

只改一个按钮？不要先动源码。

不要把旧 UI morph 掉。保留 BEFORE artifact，同时在右侧逐线生成 NOW artifact；Human 同时看见“从什么”与“变成什么”。
≈ 30 秒理解成本
03 · The missing middle

流程变化最适合的不是纯 Flowchart，而是 Wireflow

Flowchart 只告诉你“发生什么”；Wireframe 只告诉你“长什么样”。Wireflow 把 Screen + State + Transition 合在一起。
